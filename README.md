# ContractsAndInvoices

ContractsAndInvoices is a Farming Simulator 25 mod that enables player-to-player contracting on multiplayer servers.
Instead of relying only on AI-generated jobs, players can create, accept, manage, and complete contracts for real work between farms — with fair payments, clear status tracking, and a realistic workflow.

Whether you’re helping a neighbor harvest a field or running a professional contracting business, ContractsAndInvoices adds a new layer of realism and cooperation to FS25.

## Features

- Player-to-player contracts.
- Field work contracts -> cultivating, harvesting, liming and many more.
- Transport contracts -> transport goods from one place to another.
- Vehicle transport contracts -> transport vehicles from one place to another.
- Invoice payment system -> Completed a contract? Send an invoice to the owner of the contract and get paid.
- Notification system -> Be up to date on what is happening with your contracts.
